# Bamboo downloads

This public repository hosts Bamboo release downloads. The application source code is maintained in a separate private repository.

## Internal test build

The [macOS arm64 internal test DMG](https://github.com/hhrhhrhhr/bamboo/releases/tag/v1.0.0-internal-20260927-chrome-auth) is available for Apple Silicon testing. It is ad-hoc signed and **not notarized**. macOS may block the app on first launch. Read the release notes for its SHA-256 checksum and known issues.

A stable macOS release will follow Developer ID signing, notarization, and full packaged-app verification. Future updater assets such as ZIP files and `latest-*-mac.yml` will appear with the appropriate releases.

GitHub's automatically generated “Source code” archives for this repository contain this README, not Bamboo application source code.
