# Bamboo downloads

This repository contains Bamboo release downloads only. The application source code is maintained in a separate private repository.

Releases will appear after Developer ID signing, notarization, and packaged Cowork VM validation pass. No installer is published yet.

Download the macOS DMG for your Mac architecture from [Releases](https://github.com/hhrhhrhhr/bamboo/releases). The ZIP files and `latest-*-mac.yml` files are used by the in-app updater.

GitHub's automatically generated “Source code” archives contain only this README and do not contain Bamboo application source code.
